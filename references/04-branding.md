# 04 名字、简介、图标、封面

四样东西各自有硬规格，**平台不会替你检查，尺寸/比例/字数错了只会在上传后被卡**。所以：先出稿 → 自检脚本量一遍 → 用户确认 → 再上传。

## 硬规格（错一条就不合规）

| 项 | 规格 | 校验方式 |
|---|---|---|
| 名字 `appName` | **≤14 字符**（按 JS `.length`，一个汉字算 1，部分 emoji 算 2），非空 | `preflight --name` |
| 简介 `slogan` | **≤14 字符**，非空，一句话卖点 | `preflight --slogan` |
| 图标 | JPG/PNG，**1:1**，≤5 MiB；建议输出 **512×512** | `preflight --icon` |
| 封面 | JPG/PNG，**3:4**（宽×4 === 高×3），≤10 MiB；建议 **1080×1440** | `preflight --cover` |

> 平台 CLI 的 dry-run **不校验**字数、比例和图片尺寸。dry-run 通过 ≠ 合规。

## 名字

### 原则

- 2–6 个字最好记，最长别顶满 14。
- 让人**一眼知道玩什么**，或者**一眼觉得有趣**，二选一，别两头不靠。
- 不用生僻字、不用繁体混排、不用中英混写（"打工人模拟器Pro" → 太满）。
- 避开：官方/小红书/第一/最强/永久 这类词；也避开和已有小工具重名的常见标题。
- 不用原版游戏的名字或其直译。

### 命名公式（每样出 3 个，凑够 10 个候选再挑）

1. **主体 + 动作**：`泡泡捏捏乐`、`猫猫接住我`
2. **叠词/拟声**：`咕噜咕噜鱼`、`咔哒咔哒锁`
3. **反差/荒诞**：`给蚊子做发型`、`帮我砍一刀树`
4. **身份代入**：`我是大厨你别催`、`值班室夜班`
5. **结果导向**：`三秒解压`、`一分钟上瘾`

### 流程

1. 出 10 个候选，分 3 组标出每组思路。
2. 推荐 3 个，说明推荐理由（一个最好记、一个最贴玩法、一个最有传播感）。
3. 让用户选或改；用户说「你定」就选最贴玩法那个。
4. 定稿后立刻用 `preflight` 量字数。

**简介**同理，写 5 条让用户选，规则：主语尽量省、动词开头、带一点情绪，不堆功能。

- 好：「30 秒捏爆所有烦恼」「手滑一次就重来」
- 差：「一款好玩的解压小游戏，支持多种玩法和排行榜功能」（超长、全是空话）

## 图标

### 设计要点（按重要性排序）

1. **48px 还能认出**：缩到 48×48 看一眼，认不出就重做。
2. **一个主体，居中偏上**：不要三个元素挤一起。
3. **颜色 ≤3 种**，背景和主体要拉开对比（手机上图标很小）。
4. **不写小字**：图标里的字不超过 2 个，且要够大；AI 生成的图**经常把字画成乱码**，能不写就不写。
5. **不用平台 logo、不用原版角色**、不用真人照片。
6. 边缘留 8% 安全边距，圆角由平台裁，不要自己画圆角边框。

### 生成流程

1. 先定**方向 3 选 1**（给用户看三句话描述+色板，不先生成图）：`扁平角色` / `像素物件` / `极简图形`。
2. 用户选方向后再生成，一次出 2–4 张备选。
3. **自检**（逐条过）：
   - [ ] 512×512、1:1、PNG、<5MiB
   - [ ] 缩到 48px 主体还清楚
   - [ ] 没有乱码文字、没有多余手指/多只眼睛这类 AI 崩坏
   - [ ] 和封面同一套视觉（同色系、同风格）
   - [ ] 不像任何已有品牌/游戏角色
4. 给用户看，明确问「这张可以吗，还是换方向」。
5. 用户不满意 → 走下面「兜底：给提示词」。

### 图片提示词模板（自用，也能直接给用户）

> 512×512 正方形图标，<主体一句话>，<风格：扁平插画/像素/极简几何>，<主色>为主色、<辅色>点缀，纯色背景，主体居中略偏上，粗轮廓线，高对比度，无文字，无边框，无阴影特效，适合 App 图标，缩到很小仍然清晰。负面：文字、水印、logo、渐变杂乱、多个主体、写实照片、3D 渲染过度、复杂背景。

封面提示词模板：

> 3:4 竖版封面（1080×1440），<主体>占据画面中央约 60%，背景<颜色/纹理>，上方留出放标题的空间，整体<风格>，明亮饱和，手机小图也清晰，无文字（文字后期加或只放 2–4 个大字）。负面：小字、密集装饰、模糊、水印、真实品牌 logo。

## 封面

### 设计要点

1. **3:4 竖版**，1080×1440。
2. 手机信息流里是缩略图看，**主体占 60%、标题 3–6 个大字**，字高至少占画布宽度的 1/6。
3. 四周留 80px 安全边距，重要内容别贴边。
4. 和图标同一套色；封面可以是「图标主体 + 大字 + 一点玩法元素」。
5. 不堆 5 个卖点、不写长句。

### 生成流程

和图标一致：定方向 → 生成 → 自检（比例、字可读、无乱码）→ 用户确认。

**文字怎么办**：AI 生图写字容易崩。推荐做法是**让 AI 画无字底图，再用代码叠字**：

```js
// 一次性的出图脚本：底图 + 居中大字，输出 1080×1440 PNG
// 用 Node 的 canvas 或浏览器页面画，别依赖装环境
```

最简单可靠的方式：写一个临时 `tools/make-cover.html`，用 `<canvas>` 画底图 + `ctx.fillText` 叠字，浏览器里导出 PNG。这样字一定是真的字。

## 兜底：用户要拿去别的 AI 生成

当图标/封面反复不达标，或者用户想自己用 Midjourney / 即梦 / GPT 出图时，给一段**可以直接粘贴的完整提示词**，并附保存要求：

```
请用这段提示词生成一张图片：
<prompt>

生成后请按下面要求存：
1. 图标：正方形，导出 512×512 PNG；
   封面：3:4 竖版，导出 1080×1440 PNG。
2. 不要带文字和水印（文字我来加）。
3. 存成：<工具名>-图标.png / <工具名>-封面.png
4. 直接把图片发我，我帮你检查比例和尺寸。
```

用户发回来后：跑 `preflight --icon/--cover` 量一遍，不对就告诉他哪里不对（「这张是 1024×1024 但被裁成了 4:5，麻烦按 3:4 重出」），别自己拉伸图片凑比例——**拉伸会变形，宁可不合格也不许变形**。

## 自检命令

```bash
node scripts/preflight.js --dir ./dist \
  --name "泡泡捏捏乐" --slogan "30秒捏爆烦恼" \
  --icon "release/泡泡捏捏乐-图标.png" \
  --cover "release/泡泡捏捏乐-封面.png" \
  --version 1.0.0
```

只看 `images` 段：`ratio`、`bytes`、`width/height` 三项。全部 PASS 才往下走。

## 交付前最后一眼

- [ ] 名字、简介放进 14 字框里都不溢出（平台列表页会截断，超了很难看）
- [ ] 图标和封面放在一起像同一套东西
- [ ] 图标在浅色和深色背景上都看得清（平台背景色不确定，主体要有描边或底色块）
- [ ] 三样东西里没有出现任何原版角色/品牌
- [ ] 用户明确说过「这套可以」
